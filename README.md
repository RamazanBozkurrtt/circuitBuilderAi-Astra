# circuitBuilderAi-Astra

Product V1 is a two-board B2B ANC system: Board A (Controller + Audio AFE)
and Board B (Power + Stereo Class-D), with four microphone inputs and two
secondary speaker outputs.

The [Product V1 architecture](docs/product/ANC_B2B_Custom_PCB_2_Kart_Mimari_Tasarim_Dokumani_v1.0.docx)
is the product-level source. The [Phase R0 rebaseline](docs/rebaseline/phase_r0_b2b_two_board_rebaseline.md)
records its open decisions and the proposed repository migration.

The existing [KiCad project](hardware/kicad/) and earlier phase records are
**legacy four-output design history**, not Product V1 production files. Product
V1 KiCad projects have not been started.
