# Legacy KiCad project

All KiCad files in this directory belong to the former single-board,
ADAU1978 / ADSP-21569 / TAS6424E-Q1, four-speaker architecture. Preserve
them as engineering history. They are **not** Product V1 production files or
schematic-entry authority.

Product V1 is the two-board design in
[`docs/product/`](../../docs/product/ANC_B2B_Custom_PCB_2_Kart_Mimari_Tasarim_Dokumani_v1.0.docx).
Its future Board A and Board B KiCad projects belong in separate directories
under `hardware/product_v1/` after a separately authorized schematic gate.
